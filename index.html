03 — Closed-Loop Instrumentation

Hydrostatic Pressure Test Rig with PID Control

Closed-loop hydrostatic pressure test rig combining a PID-controlled electropneumatic regulator with the 24-bit strain gauge instrumentation system (Project 01) to characterise material mechanical properties. Data logged as JSON via ESP32-S3 to SD card and post-processed in Python to extract Young's modulus. PCB housed in an IP-rated steel enclosure with shielded cabling for EMI protection.
